# FitNest 🏋️

## Overview

FitNest is an AI-powered fitness and nutrition tracking web application designed to help users maintain a healthier lifestyle. It provides tools to monitor daily nutrition, track physical activities, and generate personalized workout plans using artificial intelligence.

## Objectives

- Promote healthy eating habits
- Encourage regular physical activity
- Provide personalized workout recommendations
- Simplify fitness tracking with AI assistance

## Features

- User Authentication
- Dashboard with fitness summary
- Food Logging
- Activity Tracking
- AI Food Image Analysis
- AI Workout Planner
- User Profile Management
- Responsive Design for desktop and mobile

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- Strapi 
- Strapi Cloud
- Google Gemini AI

## Conclusion

FitNest combines fitness tracking with AI to provide users with a personalized and user-friendly platform for managing their health and wellness.
